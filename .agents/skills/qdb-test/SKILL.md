> **中文说明**：提交前必须跑通整库测试。已实现的行为要有正常、边界、异常用例。复权、交易日历和多写入者不是本库的测试范围。覆盖率、loom、基准和 fuzz 还没接入，不能写成已经通过。

# QDB 自动化测试

## 提交前（completion：整库测试通过）

写完代码、执行 `git commit` 之前：

```bash
cargo test --workspace -- --test-threads=1
```

失败则停止提交，先修到通过。`--test-threads=1` 让实例锁测试和 HTTP 集群测试按顺序跑。只跑其中一个 crate 不能代替整库，除非本次改动明确只在该 crate，并且整库测试在同一轮里已经通过。

性能断言用设计里的倍数或时限，不用某台机器的 `ops/sec`。`qdb-bench` 只打印分布，不放进 `cargo test`。

单独跑一个测试和跑整库，结果必须相同。测试不使用随机数，不依赖「现在」的墙上时钟来决定事件时间，也不共享可写目录、端口或实例锁。事件时间由调用方传入。心跳、切换时限这类必须看墙上时钟的用例，把等待写死在断言里，并且仍使用独立目录。

## 分层

单元测试放在对应 crate 的 `#[cfg(test)]` 里，测纯函数。集成测试放在各 crate 的 `tests/`，以及验收套件 [`crates/qdb-suite`](../../../crates/qdb-suite)。每个文件单独编译，只调用 `pub` 接口。`qdb-suite` 用夹具独占临时目录，事件时间从固定 UTC 纪元加偏移。两类测试都要碰到正常值、边界值、异常值。

| 层 | 已经要覆盖的行为 |
|---|---|
| 布局与时间 | 帧和 K 线槽往返；截断和坏校验和被拒绝；UTC 的秒、分、日和 4 小时边界；时间戳 `0` 和负数不 panic |
| 聚合 | 成交直接聚成各周期，包含 `1m`、`5m`、`1d`。同一输入重放两次结果相同。迟到不改已闭合 K 线。缺号不闭合。别的交易所不被这次时钟收线 |
| 索引与表 | 等值索引只返回匹配行。主键冲突失败。空表查询得到空结果，不是错误 |
| 共享内存 | 映射创建和 `release` 之后可以再打开。慢读者观察到被套圈，而不是静默跳号 |
| 写入到查询 | 写入后用公开查询读到同一行。批量写入后的成交和 K 线与预期逐行一致 |
| 订阅 | 只收到过滤条件里的标的。其他标的不出现。`from_seq` 续传。序号空洞得到 gap。同一条增量 `SELECT` 的多个 WebSocket 都收到同一批新行；队列满的连接收到 `gap` 并关闭，其他连接继续 |
| 订阅结束 | 读者关掉或进程退出后，写入者继续写入，不因为这个读者停住 |
| 恢复 | 删掉共享内存后从快照加 WAL 回到同一 `seq` 和同一批行。快照加增量与只重放 WAL 的结果一致。坏 CRC 或截断停在最后一条好记录之前，拒绝继续写入 |

行情文本解析用仓库里的样例字节，不访问新浪或任何交易所。外部字节进入引擎之前先变成成交或报价；解析函数对空串、缺字段、超长字段返回错误，不 panic。

下面这些不测，也不要为了测试把它们加进库：复权因子、交易日历、节假日、非交易时段、时区换算。时钟只认调用方给出的 UTC 纳秒。

## 并发

引擎只有一个写入者。测试用一个写入者和多个只读查询同时跑，断言不 panic、查询能读到已经发布的行、写入者不因为读者变慢而停住。第二个 `qdb` 进程必须在打开库之前失败，这就是多写入者的边界。

环形缓冲和 seqlock 的调度穷举见下面「尚未接入的门禁」。在那之前，并发证据是现在的单写多读测试和故意放慢的读者。

## 覆盖范围

测试只覆盖 **已经实现** 的公开行为。依据是：

- [`docs/design.md`](../../../docs/design.md) 里第一版已经落地的条款
- 各 crate 的公开函数
- 本轮新增、且代码里真实存在的行为

[`docs/2026-10-19-enterprise-broker-md.md`](../../../docs/2026-10-19-enterprise-broker-md.md) 和 [`docs/2026-10-19-distributed-ha.md`](../../../docs/2026-10-19-distributed-ha.md) 里标明未实现的能力，不要写成已通过的测试。

新功能合入时，同一变更里加上测试。期望值来自设计中的具体数字或独立算好的时间边界，不用实现代码再算一遍当作期望。

## 每个功能至少碰到的边界

| 区域 | 要有的用例 |
|---|---|
| 布局 | 定长、往返编码、截断输入、校验和被改坏 |
| 时间 | UTC 秒/分/日边界，4 小时边界，负时间不 panic |
| 环形缓冲 | 跟上时序号连续，写满后慢读者得到 gap，容量不是 2 的幂被拒绝 |
| WAL | 空文件、往返、尾部半截记录不算损坏，坏 CRC 停在前一条 |
| 聚合 | 设计中的三笔成交、重放、缺号、迟到、时钟收线、别的交易所不被收线 |
| 引擎 | 删掉共享内存仍可恢复，坏 CRC 拒绝新写入，时钟水位可重放，重复登记符号不新增序号 |
| 多库 | 非法库名、重名、库之间成交隔离、根目录已有 WAL 仍是 `default` |
| 转储恢复回放 | 空库才能恢复、坏魔数或坏 CRC 被拒绝、半截转储不算损坏、恢复后的成交和 K 线与转储前一致、回放不改写源库 |
| 建表 | 只接受 INT64、STRING、BOOL；重名表、未知类型、主键冲突失败；复合主键按整行判重；索引等值查找不带回其他行；字符串 1024 字节通过、1025 失败；重启后表和行还在 |
| SQL | 见下面「当前 SQL」。改语法时先改那一节，再补对应测试 |
| 订阅 | 过滤、有序续传、序号空洞得到 Gap、未知代码失败 |
| 复制 | 复制 ID 对得上只发增量，对不上从 0 全量；偏移超过已落盘位置被拒绝；更高任期停止旧写入者；只读打开拒绝再写 |
| 可见性 | 门闩打开后，只读打开看不到还没 `publish_visible` 的成交；发布到较早偏移时，更晚的成交仍不可见 |
| 集群与切换 | 槽外写入返回 421，槽内返回 200；空键槽号是 0；槽表有缺口或重叠时拒绝；`QDB_FAILOVER_MS=200` 时，主进程退出后 2 秒内副本升主；`0` 关闭自动切换 |
| 性能 | 48 笔成交的一次组提交，耗时小于逐条 `fsync` 的三分之一；512 笔、每 256 条一批时，`flush_count` 不超过 4，且 15 秒内完成；券商席位开盘在 `a_broker_desk_opening_keeps_venues_apart_and_closed_bars_intact`；256 个订阅者同时跟上在 `many_desk_subscribers_catch_up_while_the_writer_keeps_going`；128 路 WebSocket 各收各的标的在 `many_websocket_subscribers_each_get_their_own_symbol` |
| 健康 | 无心跳可用，CRC 或缺口不可用，心跳超过 2 秒不可用 |
| 实例 | 同一把实例锁上，第二个 qdb 进程启动失败，且不会先打开库 |
| 行情中心 | 组提交在 flush 前不增加落盘次数；五档报价往返；from_seq=0 返回当前快照；检查点之后前缀损坏仍能打开；停牌只有报价、时钟只收本交易所、128 只证券各留自己的一笔、64 路查询读到同一收盘价、删掉共享内存后席位簿仍在，见 `qdb-suite` 的 `broker_ops` |
| 退出 | `release` 后内存表为空，WAL 仍能再打开；SIGTERM 后进程退出并打印已释放内存 |

## 当前 SQL

只测 [`docs/manual/sql.md`](../../../docs/manual/sql.md) 里已经写明的语法。新语法先按 [`docs/manual/index.md`](../../../docs/manual/index.md)「后续增补」写进那一章，再改下面的表并补测试。下面每一条都要有测试名。子查询、`UPDATE`、窗口函数、连接上的聚合，断言为失败，不能当成已支持。`DELETE` 只覆盖有主键的用户表。

| 写法 | 必须碰到的边界 |
|---|---|
| `SELECT` 列或 `*` | 缺 `FROM`、未知列、关键字大小写、末尾分号 |
| `WHERE` | `symbol`、`period` 缺失或未知；`ts BETWEEN` 含两端；`snapshots` 无 `symbol`；`symbols` 忽略 `symbol`；`<`、`>`、`<>`、`AND`、`OR`、`IS NULL`、`IS TRUE`、`IS FALSE`、`IS UNKNOWN`，谓词本身只有真或假；`symbol` 只写在 `OR` 里时 `klines` 失败 |
| 聚合 | `MAX` `MIN` `SUM` `AVG` `COUNT` `FIRST` `LAST` 各一次；未知函数失败；空结果是空文本；非聚合列不在 `GROUP BY` 里失败 |
| `ORDER BY` / `GROUP BY` / `HAVING` / `DISTINCT` | `ORDER BY` 在 `LIMIT` 前排序，整数按数值；`GROUP BY` 每个键一行，分组键可以是表达式；`HAVING` 过滤分组；`DISTINCT` 去重；`AS` 别名可用于 `ORDER BY` |
| 表达式 / `CASE` / `IN` / `LIKE` / `UNION` | `*` 比 `+` 更紧；整数除法向零截断；除以 0 失败；`000001` 仍按原文本返回；`CASE WHEN` 和 `CASE 列 WHEN 值`，空值不会命中另一个空值；`COALESCE` 取第一个非空值，空字符串不算空值；`NULLIF` 只在两边相等时变成空值；`CAST` / `::` 在 `INT64`、`STRING`、`BOOL` 之间转换，空值保持空值，转不成则失败；`IN` 含空值且不相等时无行；`LIKE` 的 `%` 和 `_`；`ILIKE` 不区分大小写，通配符相同；`UNION` 去重，`UNION ALL` 保留，列数不同失败；`INTERSECT` 比 `UNION` 更紧；括号先算内层，可以改这个优先级，里面的 `ORDER BY` 和 `LIMIT` 先生效；`EXCEPT` 去掉右边有的行；`ALL` 按出现次数 |
| `LIMIT` | 缺省 1000；`0` 得到空；`100000` 通过；`100001` 失败；缺数字失败 |
| `SUBSCRIBE` | 只从 `SELECT` 末尾剥掉；`query` 遇到它失败；`SHOW` 末尾失败 |
| `SHOW` / `DESCRIBE` / `DESC` | 四张行情表和用户表；未知表失败 |
| `CREATE TABLE` / `INSERT` | 三种类型；空定义、列数不对、类型不对、保留表名、主键冲突失败；`EXPECT` 序号不符时不写，相符时覆盖并得到新 `seq`；`EXPIRE AT` 记下 UTC 纳秒截止时间；多个元组先检查再提交，后一行冲突时整句不写，多个元组不能带 `EXPECT`；列清单是建表列的排列，缺列、重复列或未知列整句不写 |
| `EXPIRE AT` | 水位命中非 0 截止时间的主键并写成墓碑；未到期和没有截止时间的行还在；重放不看本机时钟 |
| `DELETE` | 主键等值删掉可见行；单列主键 `IN` 一次删多个；复合主键用 `(列, ...) IN ((值, ...), ...)` 一次删多个完整键，列顺序不限；缺一个或重复则整句不写；重启后仍不可见，同一键可以再插入；缺主键、非 `CREATE TABLE` 的表、不存在的键失败 |
| `DROP TABLE` | 调用方表从查询和 `SHOW TABLES` 消失，WAL 保留记录；同名可以再建且是空表；内置表和不存在的表失败；重启后仍不在 |
| `TRUNCATE TABLE` | 定义还在，可见行清空，可以再插入；没有主键的表同样清空；内置表和不存在的表失败；重启后清空前的行不可见 |
| `JOIN` | `INNER`、`LEFT`、`RIGHT`、`FULL`、`CROSS`；`OUTER` 和 `AS`；`ON` 的 `AND`；缺 `ON`、重复别名、`CROSS` 带 `ON`、重名列、连接上的聚合都失败；连接后引用不存在的列失败，存在的列可以 `BETWEEN`；补出来的空列不再匹配空字符串 |

## 写法

- 通过公开接口断言，不读私有字段。
- 一个测试只讲一件事，名字写出条件和结果。
- 用例之间不共享可变目录。临时目录用进程号区分，结束删除。每个测试从空目录构造自己的数据。
- 构造成交、报价和 K 线时传入事件时间、价格和成交量。价格用 `i64`。同一段输入重复跑，行和 `seq` 不变。
- 不访问外网，也不连真实交易所。测 HTTP 时只连本机 `127.0.0.1` 上的 `qdb` 进程。

## 尚未接入的门禁

下面是后续要接上的检查。仓库里还没有对应的 CI、覆盖率阈值、loom 测试、Criterion 基准和 fuzz 目标。没有接上之前，测试报告不写「覆盖率已达标」或「loom 已通过」。接上之后，任一失败就挡住合并。

| 门禁 | 要求 |
|---|---|
| 格式 | `cargo fmt --all -- --check` |
| Clippy | 本地可以是警告。CI 使用 `cargo clippy --workspace --all-targets -- -D warnings`。配置写在工作区 `[workspace.lints.clippy]` 时，每个 crate 要有 `lints.workspace = true`。测试代码可以在 `clippy.toml` 里放行 `unwrap` |
| 覆盖率 | 用 `cargo llvm-cov` 或 tarpaulin 出报告。核心 crate 行覆盖率不低于 80%。`qdb-sql` 解析、`qdb-agg`、`qdb-wal` 恢复不低于 90%。低于阈值则 CI 失败 |
| loom | 只测环形缓冲和 seqlock。生产代码默认用标准库原子量；`cfg(loom)` 下改用 loom 的原子量、互斥锁和线程。测试里的调度都从 loom 来。模型仍是一个写入者和多个读者 |
| 压测 | 一个写入者和多个只读查询同时运行一段时间。断言不 panic、已发布的行不丢、进程内存不随着重复查询无限增长 |
| 基准 | `cargo bench` 尚未接入。生产负载用 `cargo run -p qdb-server --bin qdb-load --release`：预热不计入，同一负载 3 轮，报告 p50 / p99 / p999。数字只描述当次机器，不写进 `cargo test` 的合格线 |
| fuzz | 对 SQL 文本、WAL 字节、行情 JSON 和行情文本做 fuzz。畸形长度、缺字段、超大整数、非数字价格都要拒绝或跳过，不 panic，也不把 `NaN` 写进价格。价格继续用 `i64` |
| CI | 合并前跑格式、Clippy、`cargo test --workspace -- --test-threads=1`、覆盖率。loom 和 fuzz 单独一个任务。基准按计划比较历史结果，回退时要有说明 |

订阅者变慢时，写入者不等待；读者得到 gap，停止把后续帧当成连续数据。这个行为以 [`docs/design.md`](../../../docs/design.md) 为准。重连从 `seq` 续传：缺号报 gap，同一 `seq` 不重复交付。
