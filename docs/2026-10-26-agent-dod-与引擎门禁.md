> 手册权威：[`docs/manual/`](manual/index.md)（`server.md` / `limits.md` / `data-model.md`）。

## 1. 为何需要

流水线角色与设计硬约束已有，但代理易在「代码已写 / 单测绿」处停住，缺少**可复现证据**与**运行态对齐**（重建二进制 → HTTP/SQL 冒烟 → 手册同步）。本页把验收剧本写死，减少口头「好了」。

## 2. 分级与最小证据

| 级别 | 最小证据包 |
|---|---|
| hotfix | 复现命令变绿 + 相关回归 1 条 |
| feature | 验收表 + 冒烟摘录 + 手册/设计 diff 指针 + DoD 落盘 |
| epic | 上者 + 架构增量或容量说明 + 整库回归绿 + Review 无阻断 |

## 3. HTTP / 引擎验收剧本

顺序固定：

```text
1. 重建：cargo build -p qdb-server   # 或 docker build / compose recreate
2. 整库：cargo test --workspace -- --test-threads=1
3. 启动：QDB_FEED=0 cargo run -p qdb-server --bin qdb -- <tmpdir>   # 无外呼时测写入
4. 写入若干 quotes/trades（或允许 feed 的本地冒烟）
5. curl /health、/v1/snapshots、/v1/klines、/v1/docs（按改动裁剪）
6. 若改恢复：停进程 → 删 shm → 再启 → 核对 applied_seq / K 线
7. 行为变更：同一 diff 更新 docs/manual/ 对应章
```

示例（按改动裁剪；冒烟端口建议避开常驻 9090）：

```bash
cargo test --workspace -- --test-threads=1

PORT=19090
QDB_HTTP_PORT=$PORT QDB_FEED=0 cargo run -p qdb-server --bin qdb -- /tmp/qdb-dod-data &
curl -s "http://127.0.0.1:${PORT}/health"
curl -s -X POST "http://127.0.0.1:${PORT}/v1/quotes" \
  -H 'content-type: application/json' \
  -d '{"items":[{"exchange":"SSE","code":"600519","ts_ns":1,"last":13250000,"price":1325.0,"open":1322.5,"high":1348.6,"low":1321.0,"pre_close":1329.0,"volume":1,"amount":1,"name":"贵州茅台"}]}'
curl -s "http://127.0.0.1:${PORT}/v1/snapshots?symbols=SSE:600519"
curl -s "http://127.0.0.1:${PORT}/v1/klines?symbol=SSE:600519&period=1m&limit=10"
# docs 键由采集或测试写入；无数据时 404 可接受，但本改动若声明写入则须非空
curl -s "http://127.0.0.1:${PORT}/v1/docs?key=ashare:codes"
```

**失败判定**：

- 只改了源码、未重建进程就报绿；**仅 `/health` 绿不算引擎完成**
- 破坏 `/v1/snapshots|klines|docs|quotes|trades` 形状却未改手册、未写版本说明
- klines `limit` 超过手册上限 5000 却无说明
- 写入语义变了却未同步 late-tick（早于当前桶 → 进 ticks、不进已闭合 K 线）
- 第二实例能抢写；或把未实现能力写入手册当已交付

## 4. 环境与契约陷阱

| 项 | 错误完成态 | 正常 |
|---|---|---|
| 旧二进制 | 宿主机改码未 rebuild | 本轮二进制/镜像已重建 |
| `QDB_FEED=0` | 期望 health 常绿却无写入 | 测读路径前先 POST 或开 feed；无心跳时 503 可能是预期 |
| EquityLab 同级仓 | 静默改 `/v1` 字段名/语义 | 手册版本表 + DoD「已知风险」写清客户端影响 |
| `abi_version` / 帧布局 | 只改代码不改设计 | 先改 `docs/design.md` |

本仓不实现 EquityLab 的 collector / 前端；那些门禁留在 EquityLab 的 DoD。
