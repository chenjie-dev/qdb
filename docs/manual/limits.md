# 限制

本页只列 0.1.0 已经确定的边界。设计里预留、代码里还没有的能力，不出现在前面的语法和接口章节。

## 容量

| 项 | 当前值 |
|---|---|
| 帧 | 256 字节，载荷最多 208 字节 |
| 交易所标签 | WAL 保留 16 字节 |
| 证券代码 | WAL 保留 32 字节 |
| 库接口打开时的共享内存 | 1024 个符号槽，4096 帧 |
| `qdb` 进程打开时的共享内存 | 65536 个符号槽，65536 帧 |
| SQL 默认行数 | 1000 |
| SQL 最大行数 | 100000 |
| 报价档位 | 五档价格和数量写入 WAL。`SELECT` 可用 `bid_px1` 到 `bid_px5` |
| 周期 | 7 个，固定集合 |
| WAL 文件 | 每个库一个 `wal/wal-1.qwal` |
| 库名 | 字母或下划线开头，最长 32 字节 |
| 监听地址 | 缺省 `127.0.0.1`，可用 `QDB_HTTP_ADDR` 改 |

环形缓冲写满前读者必须消费，否则下一次读取返回 `Lapped`。

## 语义

- 时钟是 UTC。库没有时区表，也没有交易日历。
- 交易所标签不携带会话、复权或涨跌停规则。
- 价格是调用方缩放后的整数。`price_scale` 不参与计算。
- 已闭合 K 线只追加。修正已闭合 K 线的接口还没有。
- 早于当前桶的成交进入 `ticks`，不进入 K 线。
- SQL 的 `ORDER BY` 在 `LIMIT` 之前排序。`GROUP BY` 每个分组键一行。单表扫描最多 100000 行。表达式是整数，除法向零截断。
- `klines` 的 SQL `seq` 列恒为 `0`。
- `symbols.exchange` 是调用方标签。内部编号在 `exchange_id` 和 `symbol_id`。展示代码在 `symbol`。
- 同一 `seq` 的多帧里，续传只交付过滤后的第一条。
- 订阅的 `from_seq = 0` 只给出快照边界和尚未应用的帧，不回放历史帧。
- 健康检查在 2 秒没有新写入后变为 503。采集线程的写入会刷新心跳；`QDB_FEED=0` 时仍没有后台时钟。
- 坏 CRC 使引擎只读。

## 本版本不提供

这些项在设计文档里有位置，调用当前版本不会得到对应行为：

- PostgreSQL 线协议。本机查询、`.watch` 和 `SELECT ... SUBSCRIBE` 见 [客户端](client.md)。WebSocket 推送见 [服务进程](server.md)
- gRPC、TCP 长度前缀订阅
- 账号、权限和审计
- 历史导入、复权、公司行为和多档订单簿
- 槽位表在主节点切换后不会自动改写

需要其中一项时，先改设计再实现。在此之前，业务系统通过本手册里的库接口写入和读取。
