# QDB 文档

QDB 0.1 是单机内存行情库。一个写入者把成交、报价和时钟写入 WAL，更新内存里的 Tick、K 线和快照，再把触发帧发布到本机共享内存。查询和订阅读的是这份内存状态。

本手册说明怎么用。实现约束和尚未实现的设计分别在 [设计正文](../design.md)、[券商级能力清单](../2026-10-19-enterprise-broker-md.md) 和 [分布式设计](../2026-10-19-distributed-ha.md)。

功能迭代时，同一变更更新受影响的章节。手册只记录当前已经实现的用法；还没做的能力留在设计文档里。章节就地修改，不另建日期副本。

## 给第一次使用的人

1. [教程](tutorial.md)：准备数据目录，写入一笔成交，用 SQL 读出 K 线。
2. [概念](concepts.md)：序号、UTC 时钟、交易所标识、单写多读。
