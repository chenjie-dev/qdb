# QDB 文档

QDB 0.1 是单机内存行情库。一个写入者把成交、报价和时钟写入 WAL，更新内存里的 Tick、K 线和快照，再把触发帧发布到本机共享内存。查询和订阅读的是这份内存状态。

本手册说明怎么用。实现约束和尚未实现的设计分别在 [设计正文](../design.md)、[内存库要求](../2026-10-29-memory-db-requirements.md)、[券商级能力清单](../2026-10-19-enterprise-broker-md.md) 和 [分布式设计](../2026-10-19-distributed-ha.md)。

功能迭代时，同一变更更新受影响的章节。手册只记录当前已经实现的用法；还没做的能力留在设计文档里。章节就地修改，不另建日期副本。

## 后续增补

以后增加或改变使用者能看见的行为时，同一变更里把手册补到和 [SQL](sql.md) 同一详细程度。只改代码、或只在章节末尾加一句话，不算完成。

新语句、新子句、新 HTTP 路径、新错误或新限制，在对应章写全这些条目里适用的部分：

| 条目 | 要写清的内容 |
|---|---|
| 语法 | 能抄进调用处的写法。关键字、参数顺序、可省略的部分 |
| 说明 | 它做什么，结果按什么顺序产生 |
| 参数或输出 | 每个参数的单位和合法取值；返回的列、字段或状态码 |
| 注意 | 边界、空值、默认值和失败时的文案 |
| 示例 | 一条能照着运行的例子 |
| 兼容性 | 和已有行为或 PostgreSQL 不同的地方。没有差异就省略 |

同时改这些位置：

- 新的 SQL 写法和边界：改 [SQL](sql.md)，并改 `.agents/skills/qdb-test` 的「当前 SQL」，再补测试。
- 新的错误文案：改 [错误](errors.md)。调用方要匹配的类型和 `Display` 句子都写上。
- 新的容量、默认值或环境变量：改 [限制](limits.md)。若是 HTTP，同时改 [服务进程](server.md)。
- 目录有新章时，更新本页的参考表。

未实现的语句、路径和参数不要写进手册正文。它们留在 [设计正文](../design.md) 或带日期的设计文档里。
